02 / Why constant pen speed

同一幅图，同一时钟 · only the duration rule changes

NAIVE equal duration

Every stroke gets 620 ms. A 1,197-unit contour and a 6-unit tick finish together.

INK-MOTION length / speed

Each stroke gets its measured length divided by 620 units per second. The pen keeps one speed.

0.00 / 0.00 s

Both panels start with identical SVG, identical delays and the same number of strokes. The only difference is duration = 620 ms versus duration = length / speed. Equal durations make long contours sprint and short ticks crawl; length-derived durations read as one pen moving across the page. The comparison uses the archive drawing; the workbench switches all four.

04 / Use

两行接入 · no build step

<svg class="ink" viewBox="70 125 470 415" data-ink>
  <path data-ink-draw data-ink-delay="0" pathLength="1" d="M112 158 C200 150 …" />
  <circle data-ink-drop data-ink-delay="900" cx="262" cy="342" r="3.4" />
</svg>

// draw once, at a constant pen speed
import { playInk, scrubInk } from "./ink-motion.js";
playInk(document.querySelector(".ink"), { speed: 620 });

// …or drive every stroke from one progress value
scrubInk(document.querySelector(".ink"), {
  section: document.querySelector("#scene"),
}).bind();
